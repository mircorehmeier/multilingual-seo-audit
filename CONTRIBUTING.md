# Contributing

Small, focused pull requests are welcome.

1. Fork the repository and create a feature branch.
2. Run `npm install`.
3. Add or update tests for audit logic.
4. Run `npm test` and `npm run build`.
5. Open a pull request describing the SEO rule, expected behavior and any relevant primary-source documentation.

Please avoid adding arbitrary "SEO score" rules. Checks should be explainable, testable and tied to a concrete technical signal.
